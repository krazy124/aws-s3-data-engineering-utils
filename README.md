# AWS S3 Data Engineering Utils

A Python practice project for learning AWS S3 operations using boto3.

## Features

- Create S3 buckets
- List S3 buckets
- Upload files to S3
- Download files from S3
- List objects in a bucket
- Delete objects from S3
- Delete S3 buckets

## Tech Used

- Python
- boto3
- AWS S3

## Purpose

This project is part of my AWS and data engineering learning path. The goal is to build reusable Python utility functions for common cloud storage workflows.
